# India & Ireland AI Futures

An interactive educational portfolio project exploring Artificial Intelligence, Machine Learning, real-world AI applications, risks and ethical AI across India and Ireland.

## Features
- AI basics and types of AI
- AI → Machine Learning → Deep Learning diagram
- AI learning pipeline
- Healthcare
- Police and defence contexts
- Villages, agriculture and cities
- Corporate companies and business
- Deepfakes, privacy, bias and transparency
- Interactive chart
- Ethical AI principles

## Important data note
The fake-content/deepfake chart uses **illustrative portfolio data only**. It is not official India or Ireland crime data.
